# Browser Extensions Manager UI

A responsive browser extensions manager built as a Frontend Mentor challenge.

## Live Demo

[View live site](https://github.com/sefahanan449-byte/browser-extension-manager-ui.git)

## Features

- Toggle extensions on and off
- Filter by All, Active and Inactive
- Remove extensions from the list
- Light and dark theme (saved in the browser)
- Responsive layout for mobile, tablet and desktop
- Keyboard accessible with visible focus styles

## Built With

- HTML5
- CSS3 (Grid, Flexbox, custom properties)
- JavaScript (fetch, DOM manipulation)

## What I Learned

- Rendering cards dynamically from a JSON file
- Using CSS variables to switch themes
- Building an accessible toggle switch
